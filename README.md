# 🌦️ Weather Dashboard
[View Weather Dashboard](https://linacans347-droid.github.io/weather-dashboard/)

A simple and responsive weather dashboard built with HTML, CSS, and JavaScript.

## ✨ Features

- Select a city from the dropdown menu
- Get current weather information
- Display temperature and feels-like temperature
- Show humidity, wind speed, and wind gust
- Display a weather icon and weather conditions

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await

## 🌍 Supported Cities

- New York
- Los Angeles
- Chicago
- Paris
- Tokyo
- London

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Select a city and click **Get Weather**.

Weather data is retrieved from the freeCodeCamp weather proxy API.
